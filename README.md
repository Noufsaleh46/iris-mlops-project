\# Iris MLOps Project 🌸An end-to-end MLOps project for Iris flower classification using Machine Learning, MLflow, Docker, GitHub Actions, GitHub Container Registry, and Render.\## 🚀 Live Demohttps://iris-mlops-api-dfjx.onrender.com/Users can enter the four Iris flower measurements through the web interface and receive a prediction directly in the browser.\## 🧠 Project OverviewThis project demonstrates how to take a machine learning model from development to production.The workflow includes:\- Model training\- Model management with MLflow\- Flask REST API\- Web interface\- Automated testing with Pytest\- Docker containerization\- CI/CD with GitHub Actions\- Docker image publishing to GHCR\- Cloud deployment using Render\## 🏗️ Architecture```textUser&#x20;│&#x20;▼Web Interface&#x20;│&#x20;▼Flask API&#x20;│&#x20;▼MLflow Model&#x20;│&#x20;▼Iris Prediction&#x20;│&#x20;▼Setosa / Versicolor / Virginica🛠️ TechnologiesPythonScikit-learnMLflowFlaskHTML / CSS / JavaScriptDockerPytestGitHub ActionsGitHub Container RegistryRender📁 Project Structureiris-mlops-project/│├── .github/│   └── workflows/│       └── ci.yml│├── model/│   ├── MLmodel│   ├── model.skops│   ├── conda.yaml│   ├── python\_env.yaml│   └── requirements.txt│├── src/│   ├── app.py│   ├── predict.py│   ├── train.py│   └── templates/│       └── index.html│├── tests/│   └── test\_api.py│├── Dockerfile├── requirements.txt└── README.md🔮 FeaturesWeb InterfaceThe user can enter:Sepal LengthSepal WidthPetal LengthPetal WidthThe application sends the values to the Flask API and displays the predicted Iris class.REST APIThe prediction endpoint is:POST /predictExample request:{&#x20; "sepal\_length": 5.1,&#x20; "sepal\_width": 3.5,&#x20; "petal\_length": 1.4,&#x20; "petal\_width": 0.2}Example response:{&#x20; "prediction": 0,&#x20; "class\_name": "setosa"}🧪 TestingRun the API tests with:pytest tests/test\_api.py -vThe project includes automated API testing using Pytest.🐳 DockerBuild the image:docker build -t iris-api .Run the container:docker run -d -p 8000:8000 --name iris-container iris-apiThen open:http://localhost:8000🔄 CI/CDGitHub Actions automatically:Builds the Docker imageRuns the containerWaits for the APIRuns PytestBuilds the production Docker imagePublishes the image to GitHub Container Registry☁️ DeploymentThe application is deployed on Render and is available through the live demo.Every update pushed to the main branch can trigger the CI/CD workflow and deployment process.📊 MLflowMLflow is used for managing and loading the trained machine learning model.The production application loads the saved model from the MLflow model artifact.🎯 Project GoalThe goal of this project is to demonstrate a complete machine learning deployment lifecycle:Train&#x20;

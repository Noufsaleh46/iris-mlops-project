\# Iris MLOps ProjectAn end-to-end MLOps project for Iris flower classification using Machine Learning, MLflow, Flask, Docker, GitHub Actions, GitHub Container Registry, and Render.\---\## Project OverviewThis project demonstrates a complete machine learning deployment workflow, starting from a trained classification model and ending with a publicly accessible cloud API.The project includes:\- Machine Learning model training\- MLflow model management\- Flask REST API\- Docker containerization\- Automated API testing with Pytest\- GitHub version control\- GitHub Actions CI/CD\- GitHub Container Registry (GHCR)\- Cloud deployment using Render\- Automated deployment using a Render Deploy Hook\---\## Architecture```text&#x20; TestThe pipeline:Checks out the repositoryBuilds the Docker imageRuns the Docker containerWaits for the APIInstalls testing dependenciesRuns PytestDisplays container logs2\. PublishAfter successful tests:Docker image is builtGitHub Container Registry authentication is performedDocker image is pushed to GHCRDocker image:ghcr.io/noufsaleh46/iris-mlops-project:latest3\. DeployAfter the image is successfully published:GitHub Actions triggers the Render Deploy HookRender pulls the updated Docker imageThe cloud service is redeployedThis creates an automated deployment workflow.CI/CD WorkflowDeveloper&#x20;
